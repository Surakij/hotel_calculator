# Contributing

Thanks for helping improve Hotel Calculation.

## Before making changes

- Keep the application dependency-free unless there is a clear reason to add a dependency.
- Preserve the existing calculation logic unless the change is intentional and documented.
- Keep the interface simple and suitable for everyday tourism/hospitality work.
- Test changes in a current desktop browser before pushing.

## Pull requests

Please include:

1. A short description of the problem or feature.
2. A summary of the implementation.
3. Any calculation or UI behaviour that changed.
4. Testing performed.

For UI changes, include a screenshot when it helps explain the result.

## Commit messages

Use short, descriptive commit messages, for example:

- `Fix discount field layout`
- `Add transfer calculation`
- `Improve share text formatting`

## Code style

The current project uses plain HTML, CSS and JavaScript in `index.html`. Follow the existing style and avoid unnecessary rewrites of unrelated code.
