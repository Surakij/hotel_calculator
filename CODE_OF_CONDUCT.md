# Code of Conduct

## Our standard

This project aims to be a constructive and professional space for collaboration.

Participants are expected to:

- Be respectful and professional.
- Focus on the technical issue rather than the person.
- Give clear, useful feedback.
- Avoid harassment, discrimination and personal attacks.

## Enforcement

Unacceptable behaviour may be removed from project discussions, issues or pull requests at the repository owner's discretion.
