# Security Policy

## Scope

Hotel Calculation is a client-side static web application. It does not provide a server-side account system or application database.

## Reporting a security issue

Please do not publish sensitive security details in a public issue.

If you find a security problem, contact the repository owner privately through GitHub and provide enough information to reproduce the issue.

## Sensitive data

Do not enter passwords, payment card data, government identification numbers or other highly sensitive personal information into the calculator.
